## 一、里程碑主序

### M0 · 地基三件套（已具备·重对齐后可开工）
骨架 / 持久化层（Repository 抽象+Dexie）/ 资产注册表（schema 驱动+canonStatus）。
- **spec 依赖**：M0 任务包 v1.1 · 三承重墙决策 · canon 访问层 v1 · 数据四篇（字段源）。
- **自动化边界**：纯工程，无 spike 依赖。
- **验收闸**：200 章规模存取不崩 + repo 实现可换业务零改 + 新资产类型只填配置（任务包 v1.1 总验收）。

### M1 · 一章端到端最小闭环（嵌套两层）★本轮重心
> M1 = **M1a 引擎内核(证"对")⊂ 包上 ⊃ M1b 用户主链(证"好用")**。M1a 先跑通采数据；M1b 把用户旅程主链包上做"腰部作者能否上手"真验证。决策二在 M1(a+b)跑完后拍。

#### M1a · 引擎内核（证零漂移·决策一·内部）
**目标**：一章真正流过 ①→④→⑤→⑥（不再人扮 AI），**零漂移可测** + 采 spike 数据。
- **① 创意**：消费已裁决创意种子 fixture（逆天剑修），不做完整评估 UI。
- **④ 推演台**：产出强类型 SceneBeat + entityManifest（P0 §2）← 采 **S2 命中率**。
- **⑤ 写作台**：只消费 manifest 翻译 + 闭世界硬拒（P0 §4）+ AI 味负面清单。
- **⑥ 审校台**：守恒 + 知情图谱闭世界（认知越界·走收窄后校验非反推）+ 情绪账本 + 张力 ← 采 **S4/S1**。
- fixture 基准：逆天剑修选一代表章作金标比对。
- 屏：①(fixture)④⑤⑥（框架卷标 ④为 M1/M2·吻合）。**内部里程碑，不面向首跑用户。**

#### M1b · 用户主链（证好用·载生死线·≡框架卷§4第一批）
M1a 跑通后**随即包上**用户面：**①创意 → ⑬作品蓝本(六块·园丁/建筑师分流) → ③规划台(双视图·渐进解锁 L1) → ⑤写作 → ⑥审校**，叠**黄金三章通道+懒加载浮层+完善度面板**（贯穿①⑬③⑤⑥）。
- **为什么不可省**：流程模拟 §三把**渐进解锁 L1 列 P0·生死**，它落在 ③规划台——而 M1a 砍掉了 ③。没 M1b 验不了"腰部作者愿不愿上手"这条生死线。**M1a 证"对"，M1b 证"好用"，两者 M1 都缺不得。**
- 屏：①⑬③⑤⑥+黄金三章（=框架卷§4第一批·均三件齐对齐闸全勾）。

**spec 依赖**：P0 根治卡 · 状态切片 v1.3 · 经络 v1.3 · 情绪账本 v4.1+八族对齐 v1 · 审校台 v1 · 写作台环节契约 v1.1 · 推演台环节契约 v1 · 框架卷 v1.3§4/§6 · 渐进解锁 v1 · ①⑬③ spec。
**自动化边界（M1 一律 Plan B 起步）**：S1 已收窄为闭世界校验；S2/S3/S4 全挂人工兜底——M1 职责是**产出数据**，不在拿到数据前下注。
**验收闸**：① M1a 一章系统真跑、反推状态切片 vs 手跑基准容忍带内一致=零漂移可测；② 注入认知越界闭世界硬拒能抓出；③ 情绪账本产出{爽虐甜燃}向量；④ S2/S3/S4 各吐一数据点→喂决策二；⑤ **M1b 腰部作者首跑能走通主链且渐进解锁 L1 不劝退**（好用·主观+留存信号）。

### M2+ · 扩规模/扩屏（post-M1 闸 · 决策二在此分叉）
**拍决策二的依据 = M1 的数据点。**
- **决策二 A（建议·全 Plan B 起步）**：M1 命中率过线的 spike **逐个**切自动；扩到**一卷（30–50 章）**测循环延续 + 母本充分 + 长程累积漂移；再扩活画布合一体验层（②hub/③④⑧相机档/⑦三辐条/⑬作品蓝本）+ 多线编织。
- **决策二 B（选择性赌自动）**：M1 前先赌某 spike（如 S2）全自动，失败即降级；其余同 A。
- 两叉的 M2 实体一致：**一卷规模 + 活画布合一 + 多线**；差别只在自动化切换的激进度。

## 四、防降智机制内建
每个里程碑的"完成"= 跑该里程碑验收闸 + **若产生新裁决（如决策二），走治理卡决策双闸**（override_manifest 同批硬改）。屏级走防回退双闸（环节契约+对齐闸）。正文级走颗粒度+闭世界。三面闸全程在线。

## 五、验证并行轨（不阻断主序）
- **felt-authorship**：Max 读 M1/M2 产出拍板（只有作者能回答）。
- **读者盲测**：M2 一卷出后做小样盲测（可读性/追读欲）。
- **spike 校准回灌**：M1/M2 数据 → 调 α 系数 / 阈值 → 回灌各 spike。
