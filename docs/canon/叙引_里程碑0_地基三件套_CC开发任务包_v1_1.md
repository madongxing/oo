## M0-1 · 应用骨架

**目标**：搭起单页外壳，视图用全局状态切换，无路由库。

**产出物**
- `App.tsx`：按 **view-state** 渲染。视图模型对齐 ★1 活画布合一：
  - **hub②活世界仪表盘**＝外壳/家；
  - **活画布**＝③②④⑧ 同一画布，靠**相机档**切（远=⑧星图 / 中=③②欲望场 / 钻入=④推演场景）——**不是四个平级视图**；
  - **独立屏**＝①创意评估 / ⑤写作台 / ⑥审校台 / ⑬作品蓝本；
  - **三辐条⑦**＝抽屉或独立屏（与相机档正交）。
  - M0-1 只放**占位 + 正确的 view-state 形状**，活画布渲染本体留后续里程碑；**枚举/store 形状此刻就不能与活画布合一相反**。
- `store/uiStore.ts`（Zustand）：`viewState = { camera, mode }`（★1 唯一新增）+ 顶层屏标识；切换只改 view-state，**画布相机不另起路由**（铁律3）。
- 占位视图组件各一个（空壳，仅标题），证明切换链路通。

**约束**
- 切换只改 `currentView`，**不得出现任何 `react-router`/history 调用**。
- 视图枚举集中一处定义，新增视图 = 加一个枚举 + 一个组件，不动切换逻辑。

**验收闸**
- 切换独立屏（①⑤⑥⑬）+ 活画布相机档（远↔中↔钻入）+ hub② 外壳，view-state 正确变化、URL 不变、无路由库依赖（`package.json` grep 无 router）。
- 刷新后停留在默认视图（状态不持久属正常，M0-1 不接持久化）。

## M0-2 · 持久化层（仓储接口 + Dexie 实现）

**目标**：把"存储引擎"降级为可替换实现；业务只认接口。

**产出物**
- `repo/Repository.ts`：接口
  ```ts
  interface Repository {
    save<T>(table: string, entity: T): Promise<string>;
    get<T>(table: string, id: string): Promise<T | null>;
    query<T>(table: string, filter: object): Promise<T[]>;
    list<T>(table: string, scope?: object): Promise<T[]>;
    delete(table: string, id: string): Promise<void>;
  }
  ```
- `repo/DexieRepository.ts`：Dexie/IndexedDB 实现。
- `repo/index.ts`：导出单例 `repo`，业务只 import 这个。
- `repo/migrate.ts`：数据迁移工具骨架（版本号 + 升级钩子）。

**约束**
- 接口里**不出现任何 Dexie 类型**——纯抽象，保证日后能换 localStorage/云端实现而业务零改动（决策1 的核心）。
- 通用表：`assets / registry / projects`（铁律2），不为业务对象建专属表。
- 静态检查：除 `repo/DexieRepository.ts` 外，全库无 `import Dexie`、无 `localStorage`。

**验收闸**
- 写一个临时测试：save 1000 条对象 → get/query/list 正确返回，作用域 filter 生效。
- 把 `repo/index.ts` 的实现从 Dexie 临时切到一个内存 Map 实现，**业务测试不改一行仍通过**（证明抽象成立）。

## M0-3 · 创作资产注册表（schema 驱动）

**目标**：加模块 = 填一条注册；升级从"动手术"降为"填表"。

**产出物**
- `registry/AssetSchema.ts`：标准件九字段 schema + **`canonStatus`（🟡灰提案 / 🟢金已裁决 / 🔴缺）**——gray→gold 由作者拍板（接《防降智治理卡》决策闸）。字段权威源 = **《数据结构总表》四篇**（状态切片 v1.3 / 骨骼层+ArcMilestone+emotion_promise波形 / 经络 v1.3 / 场景分镜），不在此自拟字段。
- `registry/registry.ts`：注册/查询 API，读写走 `repo`。
- `registry/seed.ts`：注册样例资产类型验证通路，schema 对齐现行——**SceneBeat（P0 强类型：七问 + 情绪状态字段 + entityManifest）**、SevenQuestionCard（L2/L3）、ChapterOutline。字段照数据四篇取，**禁自拟占位字段**（否则即埋下与正典不一致的种子）。
- 工作室级共享：注册表跨项目共享，**项目"引用"而非"复制"**；连载靠宪法快照锁版本（决策2）。

**约束**
- 注册表读写**走 repo 接口**（坐落决策1 之上）。
- 引用非复制：项目持有的是资产 id 引用，不拷贝资产体。
- 可配置引擎家族的配置位（主轴/驱动/主角/世界/象限）**预留为注册表条目**，不硬编码（远期家族扩展用）。

**验收闸**
- 注册一个新资产类型 = 仅新增一条配置，**不改 schema、不改路由、不建表**即可被 UI 渲染、被质检挂钩识别。
- 两个项目引用同一工作室资产，改其一的引用关系不影响另一个的资产体。
